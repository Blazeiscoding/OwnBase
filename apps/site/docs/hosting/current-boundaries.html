Current boundaries

What OwnBase does not do today:

  • One server, one set of accounts. Accounts and friends do not federate between workspace servers.
  • No email. The server sends none, so a forgotten password cannot be reset by email. An admin resets it from People and passes the temporary password on privately, and the person changes it after signing in.
  • Browser notifications while closed need HTTPS. A workspace opened at a plain http:// LAN address notifies only while a tab has it open. See Notifications while the browser is closed. The desktop app notifies while it is running.
  • Search matches words, not meanings. It finds whole words, and the start of the last word typed, so deploy finds "deployed" and "deploying" but deploying does not find "deployed". It ignores accents and letter case. In Chinese, Japanese, Korean and Thai, which do not separate words with spaces, it finds the characters typed anywhere in a message, next to each other and in that order, so it can also find them across the boundary between two words. Nothing is ranked: results are newest first.
  • No SFU. Calls are a mesh, which suits small groups. See How many people a call holds.
  • SQLite and a local folder. A workspace is one SQLite database and its files on the server's disk. It cannot run on Postgres or keep files in S3. Backups can go to an S3-compatible bucket, see Backups somewhere else.
  • No signed builds. The Windows installer is not code-signed, so SmartScreen may warn. The Mac app is signed ad hoc and not notarized, so it cannot replace itself and only says when a new release is out.
  • No Linux desktop app. Releases build the desktop app for Windows and macOS. The server runs on Linux.

Test with your environment before an office-wide rollout.
